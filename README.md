## 💻 Local Development

Clone and run the portfolio locally:

```bash
git clone https://github.com/Anduamlakalehegne/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run serve
```
